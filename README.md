# UX Research Toolkit

用户研究 / 人因工程方法的工具化沉淀——把可标准化的研究流程做成可复用工具，让时间回到判断本身。

---

## 🧰 工具列表

### Interview Insight · 访谈文本结构化洞察工具
[→ interview-insight](https://github.com/ux-student/interview-insight)

基于扎根理论三级编码（开放编码 → 轴心编码 → 选择编码），将访谈逐字稿转化为「有编码、有频次、有原话、有建议」的标准化洞察报告。

- **预处理脚本**：自动分离访谈者 / 受访者发言，清洗语气词，统计高频候选词
- **编码框架**：统一三级编码规则与 5 大核心范畴（场景 · 功能 · 交互 · 物理 · 态度）
- **报告模板**：执行摘要、编码分布、痛点 P0/P1/P2 排序、可执行行动建议
- 每条洞察强制「结论 + 频次 + 原话 + 启示」四要素，可溯源、不编造
- 单份 1 小时访谈的分析耗时从 **3–4 小时压缩至 1 小时内**

---

## 🚧 规划中

- **问卷生成与信度预检工具**：标准化问卷生成、信效度自动预检
- **访谈提纲库**：半结构化访谈框架与追问体系

---

## 📏 设计原则

- **专业主导**：工具只承担确定性、重复性环节；结合业务语境的洞察与判断由研究员完成
- **可溯源**：结论必须绑定频次与原始证据，不接受无依据输出
- **数据隐私**：真实研究数据不进入仓库，示例仅使用虚构数据
